# Okey Helper by Jinchuriki

Metin2 Okey-Kartenhelfer. Solo-Leveling-Optik.

## GitHub Pages

1. Neues Repo auf github.com anlegen (öffentlich, ohne README).
2. Alle Dateien aus diesem Ordner ins Repo legen (nicht den Ordner in den Ordner).
3. Repo **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. Nach 1–2 Minuten: `https://DEINNAME.github.io/REPONAME/`

Wichtig: `index.html` muss in der **Wurzel** des Repos liegen.

## Lokal

`index.html` im Browser öffnen. Für den gemeinsamen Zähler **Alle Spieler** die Seite über Pages oder einen lokalen Server öffnen, nicht nur als Datei.
